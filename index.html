Focus

What we build

Software that treats people as individuals, engineered so it still works when everyone arrives at once.

Adaptive systems

Software that changes what it shows, asks, or recommends based on how each person is doing. We design the adaptation and the interface together, so the system's behaviour makes sense to the person using it.

AI and data-driven models

Models that learn from real usage which kind of support works, for whom, and when. Each one is tested against a simpler baseline before it reaches people.

EdTech tools

Tools for teaching and learning that match support to where each student is, in a class of thirty or a course of three thousand.

Software that scales

Engineering for adaptive products that must stay fast, reliable, and affordable as they grow from a pilot to a full rollout.

Approach

Research and development, in that order.

Our team comes from research in AI, human-computer interaction, and educational technology. We build products the way we run studies, with evidence at every step.

  1. Study the people

    We start with how people learn and work. Methods from human-computer interaction show where adaptation helps and where it gets in the way.

  2. Model from data

    We build models from real usage data and keep them as simple as the problem allows.

  3. Build the tool

    We put working software in front of people early, while changes are still cheap to make.

  4. Measure in use

    We evaluate with real users in real settings, and the results shape the next version.
